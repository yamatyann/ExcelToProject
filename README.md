# 照明オペレーション エディタ (XML連携版)

Excelで作成したタイムテーブル（進行表）をもとに、動画編集ソフト（Premiere Pro等）でそのまま読み込める**タイムライン（XMLファイル）**と**指示出し用画像（PNG）**を自動生成するツールです。

## 🌟 主な機能
- **Excelデータの直接読み込み**: 分・秒の列を指定して自動的に時間をパースします。
- **BPM連動カウントダウン**: 行ごとにBPMとカウント数（4カウント、8カウントなど）を設定し、自動でカウントダウン画像を生成します。
- **指示画像の自動生成**: テキストや色（カラーマップ対応）を画像（PNG）として焼き込むため、動画ソフト側でのフォント崩れや位置ズレが絶対に起きません。
- **アセット自動収集**: 音源（mp3/wav）や背景動画（count.mp4）を指定した出力フォルダに自動でコピーし、リンク切れを防ぎます。
- **FCPXMLエクスポート**: Premiere Proなどで読み込むだけで、すべての画像と音声が配置されたタイムラインが即座に完成します。

## 📁 使い方 (ポータブル版)
1. `ExcelToProject.exe` と同じフォルダに背景動画となる `count.mp4` を配置して起動します。
2. **「① Excel読込・範囲/列設定」**でタイムテーブルを読み込み、分・秒の列と開始行・終了行を設定します。
3. **「② テキスト配置・プロパティ」**で画面上のテキストや表示条件を調整します。ドラッグ中は画面中央や他の文字にスナップします（Altキーで無効）。
4. **「③ タイムライン」**のボタン、または **←/→キー** で行を切り替えながら確認します。
5. **「④ カウント＆BPM設定」**で各行のキューに合わせたBPMとカウントを設定します。
6. **「⑤ 編集ソフト連携」**から音声ファイルを選択し、「プロジェクト(XML)を書き出し」を実行します。
7. 出力された `project_timeline.xml` を Premiere Pro に読み込んでください。

## ⌨ ショートカット
| キー | 動作 |
|---|---|
| Ctrl+S | 上書き保存(保存先が未定なら名前を付けて保存) |
| Ctrl+Shift+S | 名前を付けて保存 |
| Ctrl+O | プロジェクトを開く |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直し |
| ← / → | 前の行 / 次の行へ移動 |
| Alt を押しながらドラッグ | スナップを一時的に無効化 |

何もない場所をドラッグすると、範囲選択で複数の文字をまとめて選べます。
